Izinkan akses lokasi
  1. Aktifkan menu Lokasi / GPS di smartphone (geser layar dari atas, lalu ketuk ikon Lokasi).
  2. Tekan tombol di bawah, lalu pilih Izinkan saat muncul permintaan lokasi.
Izin lokasi diblokir di browser

Izin yang sudah diblokir tidak bisa diubah lewat tombol. Ubah dulu di pengaturan:

  1. Ketuk ikon gembok / pengaturan di sebelah kiri alamat situs.
  2. Pilih Izin → Lokasi → Izinkan.
  3. Pastikan juga izin lokasi aplikasi browser aktif: Setelan HP → Aplikasi → Chrome → Izin → Lokasi.
  4. Kembali ke halaman ini, lalu tekan tombol di bawah.

iPhone (Safari): Setelan → Privasi & Keamanan → Layanan Lokasi (aktif) → Safari → Saat Menggunakan Aplikasi. Lalu di Safari ketuk aA → Pengaturan Situs Web → Lokasi → Izinkan.
